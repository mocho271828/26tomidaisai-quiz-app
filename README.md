# 富大祭 ゲストクイズ

2026年の富大祭で、ゲストと一緒に楽しむクイズ企画の進行に使ったアプリです。お客さんは手元のスマホで回答し、運営が司会の合図に合わせて正解を発表します。来年度のゲスト企画担当・司会・システム担当に向けて、開催準備と当日の操作をまとめています。

## 当日の3つの画面

| 誰が使うか | 画面 | 当日の役割 |
| --- | --- | --- |
| 参加者 | `/` | 参加すると英字3文字のIDが出ます。選択肢をタップして回答し、結果と表彰の呼び出しを自分のスマホで確認します。 |
| 運営 | `/operator` | 問題を選び、配信と回答開始を操作します。集計を確認し、司会の発表に合わせて「正解・結果を公開」を押します。 |
| 司会者の手元 | `/moderator` | タブレットで正答・回答分布・総合TOP5を見ながら進行します。正答は問題確定時から見えるので、手元に置く画面です。 |

通常の進行は**練習1問 → 本番5問 → 表彰**です。最初に配信した1問で操作を試し、2問目から総合得点に加えます。回答時間は10秒。時間に余裕があれば予備2問に進めます。最終問の正解発表、上位5位までの呼び出し、アンケート案内は、それぞれ運営がタイミングを決めます。リハーサルでは、この3つの合図まで司会と合わせておくと本番と同じ流れを試せます。[当日の操作と障害対応](docs/handover/OPERATIONS.md)

## 手元で進行を試す

Docker Compose、make、Python 3を使います。リポジトリのルートで `make local-env` を実行し、作成した `.env` に手元用の `POSTGRES_PASSWORD`、`DEMO_OPERATOR_PASSWORD`、32文字以上の `SESSION_SECRET` を設定します。既存環境では、その環境の `.env` とバックアップ鍵を引き継いでください。

- **初めて専用のローカルDBを作るとき**は `make local-db-reset` で架空の10問を準備して起動します。このコマンドは既存のローカルDBがある場合、確認入力なしで全削除します。
- **前回の続きから試すとき**は `make local-restart` でデータを保持して起動します。`make local-stop` で停止できます。

参加者は `http://localhost:8080/`、運営は `http://localhost:8080/operator`、司会は `http://localhost:8080/moderator` を開きます。運営・司会は初期準備時に設定した運営アカウントを使います。司会者画面に埋め込まれた参加者画面も、参加登録すると人数に数えられます。

画面はReactとTypeScript、APIはFastAPIで実装しています。回答・得点・進行状態をPostgreSQLに保存し、Redisで状態変更を通知します。年度ごとの接続先、認証情報、アンケートURLは担当者が各環境に設定します。
